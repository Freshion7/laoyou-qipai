# 🚀 耙耳朵麻将馆 - 部署上线指南

本游戏可以完全免费部署上线，支持4人在线联机。以下提供多种部署方案。

---

## 方案一：Render.com（推荐，完全免费）

Render 提供免费的 Node.js 托管，支持 WebSocket，适合麻将联机游戏。

### 步骤

1. **注册账号**
   - 访问 https://render.com
   - 用 GitHub 账号登录（免费）

2. **上传代码到 GitHub**
   - 在 GitHub 创建一个新仓库（Public 或 Private 均可）
   - 将本项目所有文件上传到仓库

3. **在 Render 部署**
   - 登录 Render，点击右上角 **"New +"** → **"Web Service"**
   - 选择你刚创建的 GitHub 仓库
   - 配置如下：
     - **Name**: `pa-erduo-mahjong`（随意）
     - **Runtime**: `Node`
     - **Build Command**: `npm install`
     - **Start Command**: `node server.js`
     - **Instance Type**: 选择 `Free`（免费）
   - 点击 **"Create Web Service"**

4. **等待部署完成**
   - 部署约需2-3分钟
   - 完成后会得到一个网址，如 `https://pa-erduo-mahjong.onrender.com`
   - 用手机浏览器打开即可开始游戏！

### 注意事项
- 免费套餐15分钟无请求会休眠，首次打开可能需要等待30秒唤醒
- 唤醒后游戏正常运行，WebSocket联机不受影响
- 完全免费，无需绑定信用卡

## 方案二：Railway.app（免费额度）

1. 访问 https://railway.app，用 GitHub 登录
2. 点击 "New Project" → "Deploy from GitHub repo"
3. 选择本项目仓库
4. Railway 会自动识别 Node.js 项目
5. 设置启动命令：`node server.js`
6. 部署完成后，在 Settings → Networking 中生成域名

---

## 方案三：Fly.io（免费额度）

1. 安装 flyctl：`npm install -g flyctl`
2. 注册：`fly auth signup`
3. 在项目目录运行：`fly launch`
4. 按提示配置，选择免费套餐
5. 部署：`fly deploy`

---

## 方案四：本地运行 + 内网穿透（最快体验）

如果想立刻和朋友联机玩，可以用本地服务器 + 内网穿透。

### 本地运行
```bash
cd pa-erduo-mahjong
npm install
node server.js
```
打开 http://localhost:3000

### 内网穿透（让外网朋友也能玩）

**使用 localtunnel（免费，无需注册）：**
```bash
npx localtunnel --port 3000
```
会得到一个公网网址，分享给朋友即可。

**使用 ngrok：**
```bash
ngrok http 3000
```

## 方案五：Vercel（仅静态页面，不推荐）

Vercel 对 WebSocket 支持有限，不适合需要实时联机的麻将游戏。如需使用，需将 WebSocket 部分单独部署。

## 游戏使用说明

### 创建房间
1. 打开游戏网址
2. 输入昵称，选择头像
3. 点击 "创建新房间"
4. 得到6位房间号，分享给朋友

### 加入房间
1. 打开游戏网址
2. 输入昵称，选择头像
3. 输入6位房间号
4. 点击 "加入房间"

### 开始游戏
1. 4人到齐后，每人点击 "准备开始"
2. 进入定缺阶段，选择不要的花色
3. 开始打牌！

### 游戏操作
- **出牌**：点击手牌选中，再点击一次打出
- **碰/杠/胡**：有机会时底部会弹出按钮
- **互动**：底部工具栏可发表情、四川方言、喝茶

## 常见问题

**Q: 免费平台会休眠吗？**
A: Render 免费版15分钟无请求会休眠，首次打开需等待约30秒。可设置定时请求防止休眠。

**Q: 支持多少人同时在线？**
A: 免费套餐足够支持几十个房间同时游戏。如需更多可升级付费套餐。

**Q: 数据会保存吗？**
A: 游戏数据存储在内存中，服务器重启后房间会清空。玩家ID存在浏览器 localStorage。

**Q: 可以加更多麻将玩法吗？**
A: 可以。麻将核心引擎已模块化，在 `server/mahjong.js` 中扩展规则即可。
