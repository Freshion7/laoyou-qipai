## 麻将概述

麻将起源于中国，是一种四人骨牌博戏，流行于华人文化圈。麻将牌通常包括：
- **数牌**：万、筒（饼）、条（索），各1-9，每样4张，共108张
- **字牌**：风牌（东南西北）、箭牌（中发白），每样4张，共28张
- **花牌**：春夏秋冬、梅兰竹菊，各1张，共8张（部分玩法使用）

**标准总数**：136张（不含花牌）或144张（含花牌）

## 四川麻将（血战到底）

### 基本信息
- **流行地区**：四川、重庆
- **用牌**：108张（只有万、筒、条，无字牌无花牌）
- **人数**：4人
- **核心特色**：定缺、血战到底、刮风下雨

### 核心规则

#### 1. 定缺
- 开局每人从万、筒、条中选一门作为"缺门"
- 胡牌时手牌中不能有缺门的花色
- 定缺后不可更改

#### 2. 行牌规则
- **只能碰、杠，不能吃牌**
- 庄家14张牌，闲家13张
- 逆时针出牌

#### 3. 血战到底
- 一人胡牌后游戏**不结束**，其余玩家继续
- 直到只剩1名玩家未胡牌，或牌堆摸完
- 胡牌者退出本局，不再参与后续出牌
- 最多可以有3人先后胡牌

#### 4. 刮风下雨（杠牌计分）
- **明杠（刮风）**：手中3张+别人打出1张，点杠者支付底分
- **暗杠（下雨）**：手中4张，每人支付底分
- **补杠**：碰后摸到第4张开杠

#### 5. 最后四张
- 牌墙剩最后4张时，已听牌玩家摸到叫牌必须胡
- 不能跳过胡牌选择不胡

### 番数计算

| 番型 | 番数 | 倍数 | 说明 |
|------|------|------|------|
| 平胡 | 1番 | 1倍 | 基本胡牌 |
| 对对胡 | 2番 | 2倍 | 全是刻子+将 |
| 清一色 | 4番 | 8倍 | 全部同一花色 |
| 七对 | 4番 | 8倍 | 7个对子 |
| 龙七对 | 5番 | 16倍 | 七对中有4张相同 |
| 带幺九 | 4番 | 8倍 | 所有面子含1或9 |
| 清对 | 5番 | 16倍 | 清一色+对对胡 |
| 将对 | 5番 | 16倍 | 258的对对胡 |
| 清七对 | 6番 | 32倍 | 清一色+七对 |
| 清龙七对 | 7番 | 64倍 | 清一色+龙七对 |
| 杠上花 | +1番 | - | 开杠补牌自摸 |
| 杠上炮 | +1番 | - | 开杠后点炮 |
| 抢杠胡 | +1番 | - | 抢别人补杠胡牌 |
| 海底捞月 | +1番 | - | 胡最后一张牌 |
| 天胡 | +3番 | - | 庄家起手胡 |
| 地胡 | +2番 | - | 闲家第一轮自摸 |
| 根 | +1番/根 | - | 每有一个四张相同 |

**封顶**：通常8番（128倍）封顶

### 计分方式
- **自摸**：其余未胡玩家每人支付 = 底分 × 倍数
- **点炮**：点炮者一人支付 = 底分 × 倍数
- **血战**：每次胡牌单独结算

## 广东麻将

### 基本信息
- **流行地区**：广东、香港、澳门
- **用牌**：136张（万筒条+字牌）
- **主要派系**：鸡平胡、推倒胡、新章、老章

### 鸡平胡规则（最流行）
- 可以吃、碰、杠
- 番型较少，共9种番型
- 胡牌需报出番型番数，由其他玩家检查
- **爆胡（封顶）**：通常3番或4番封顶
- **买马**：胡牌后可买马，中马翻倍

### 常见番型
- 鸡胡（1番）：最基本的胡牌
- 平胡（1番）：全部顺子+将
- 对对胡（2番）：全刻子+将
- 清一色（3番）：同一花色
- 混一色（2番）：字牌+一门数牌
- 大三元（3番）：中发白三组刻子
- 大四喜（3番）：东南西北四组刻子
- 杠上开花（+1番）
- 海底捞月（+1番）

## 北京麻将

### 基本信息
- **流行地区**：北京及北方地区
- **用牌**：136张
- **特点**：番型较少，胡牌几率大，上手快

### 核心规则
- 可以吃、碰、杠
- 没有常见的大番型
- 基本番型：平胡、自摸、门清、断幺九等
- 点炮者包付（点炮者一人出钱）
- 部分规则有"一条龙"、"七对"等番型

## 上海麻将

### 基本信息
- **流行地区**：上海
- **用牌**：144张（含花牌）
- **特点**：有花牌、有百搭牌，胡牌方式多样

### 核心规则
- 可以吃、碰、杠
- **花牌**：摸到花牌补牌，花牌数量影响番数
- **百搭牌**：部分规则有百搭（可当任意牌）
- **清混碰**：特殊规则，只能胡清一色、混一色、碰碰胡
- 讲究"勒子"（封顶）

## 武汉麻将（红中赖子杠）

### 基本信息
- **流行地区**：武汉
- **用牌**：136张（无花牌）
- **特点**：红中可杠、赖子万能牌

### 核心规则
- **红中**：可以随时拿来杠牌，杠后得分
- **赖子**：翻出的牌作为万能牌，可当任意牌使用
  - 赖子可以单张成杠打出
  - 赖子不能作为将牌（部分规则）
- **开口**：必须吃/碰/杠至少一次才能胡牌
- **杠牌分类**：
  - 冲杠：手中暗刻+别人打出，明杠
  - 蓄杠：碰后摸到第4张，可被抢杠
  - 暗杠：手中4张

## 长沙麻将

### 基本信息
- **流行地区**：湖南长沙
- **用牌**：万筒条+字牌（部分去掉风牌）
- **特点**：起手奖励多、缺一色、四喜、六六顺

### 核心规则
- **缺一色**：胡牌要求手牌缺少万筒条中的一门（不一定要开局声明）
- **起手奖励**：
  - 四喜：起手有4张相同，直接得分
  - 六六顺：起手有2个三张相同，直接得分
  - 缺一色：起手缺一门，直接得分
- 可以碰、杠
- 胡牌后有"扎鸟"（摸奖翻倍）

## 杭州麻将

### 基本信息
- **流行地区**：浙江杭州
- **用牌**：136张
- **特点**：爆头、财飘、杠开

### 核心规则
- **白板**：作为"财神"（万能牌）
- **爆头**：听牌后，下一轮自摸胡牌
- **财飘**：用财神（白板）打出后，下一轮自摸胡牌，翻倍
- **杠开**：杠牌后补牌自摸
- **承包**：特定情况下由一人承包所有分数
- 可以吃、碰、杠

## 东北麻将

### 基本信息
- **流行地区**：东北三省
- **用牌**：136张（部分地区用112张，去掉部分字牌）
- **特点**：带旋风杠、宝牌

### 核心规则
- **旋风杠**：持有东南西北各一张可开杠
- **中发白杠**：持有中发白各一张可开杠
- **宝牌**：翻出的牌作为宝牌，胡牌时手牌中有宝牌加番
- **夹胡**：胡中间的牌（如2万4万胡3万）加番
- **坐庄**：庄家输赢翻倍
- 部分地区必须"缺门"才能胡

## 台湾麻将

### 基本信息
- **流行地区**：台湾
- **用牌**：144张（含花牌）
- **特点**：16张牌、连庄、眼牌

### 核心规则
- **16张手牌**：起手16张，胡牌时17张（5组面子+1对将）
- **连庄**：胡牌者继续当庄，连庄越多番数越高
- **同时胡牌**：一人点炮，多人可同时胡
- **眼牌**：听牌后可起身查看其他人的暗杠和杠上第一张牌
- **花牌**：花牌影响番数，特定花牌组合有额外番型
- 番型齐全，可与国标麻将媲美

## 香港麻将

### 基本信息
- **流行地区**：香港
- **用牌**：144张（含花牌）
- **特点**：54种番型、最高13番

### 核心规则
- 番型非常丰富，共54种
- 最高番型13番（番满）
- 可以吃、碰、杠
- **花牌**：按季节/方位对应，摸到自己的花加番
- **大胡（满胡）**：特定大牌型直接满番
  - 天胡、地胡、人胡
  - 十三幺、十八罗汉、字一色
  - 大四喜、大三元、清幺九
- **抢杠胡**：可以抢明杠

## 国标麻将

### 基本信息
- **制定机构**：世界麻将组织
- **用牌**：144张（含花牌）
- **特点**：81种番型、8番起胡

### 核心规则
- **8番起胡**：胡牌至少要有8番，否则不能胡
- **番型最全**：共81种番型
- **花牌**：每朵花1番
- **不吃牌规则**：部分赛事采用
- **计分精确**：每番都有明确分值
- 是正式麻将比赛的标准规则

### 常见大番型
- 88番：大三元、大四喜、十三幺、连七对、四杠、绿一色、九莲宝灯
- 64番：字一色、小四喜、小三元、四暗刻、一色双龙会
- 48番：一色四同顺、一色四节高
- 32番：一色四步高、三杠、混幺九
- 24番：七对、七星不靠、全双刻、清一色、一色三同顺、一色三节高、全大、全中、全小
- 16番：清龙、三色双龙会、一色三步高、三暗刻、三同刻、全带五
- 12番：全不靠、组合龙、大于五、小于五、三风刻
- 8番：花龙、推不倒、三色三同顺、三色三节高、无番胡、碰碰胡、混一色、三色双龙会、妙手回春、海底捞月、杠上开花、抢杠胡

## 麻将基础术语

| 术语 | 说明 |
|------|------|
| 吃 | 用上家打出的牌与手中两张组成顺子 |
| 碰 | 用别人打出的牌与手中两张组成刻子 |
| 杠 | 四张相同的牌，分明杠、暗杠、补杠 |
| 胡/和 | 牌型符合胡牌条件 |
| 听牌 | 差一张就能胡牌 |
| 点炮/放炮 | 打出的牌让别人胡了 |
| 自摸 | 自己摸到牌胡了 |
| 门清 | 没有吃碰杠，全靠自己摸 |
| 断幺 | 胡牌没有1、9和字牌 |
| 将牌/眼 | 胡牌时的一对牌 |
| 面子/组 | 顺子或刻子 |
| 刻子 | 三张相同的牌 |
| 顺子 | 三张连续的同花色牌 |
| 庄家 | 第一家出牌的人，通常输赢翻倍 |
| 闲家 | 除庄家外的其他玩家 |
| 流局/荒庄 | 牌摸完没人胡牌 |
| 连庄 | 庄家胡牌后继续当庄 |
| 包牌/承包 | 特定情况下由一人承担所有分数 |
| 番/番数 | 计算输赢倍数的单位 |
| 底分/底注 | 每局基础分数 |

## 常见胡牌牌型

### 基本胡牌型
- **4面子+1将**：最标准的胡牌型（13张听，14张胡）
- **七对**：7个对子（13张听，14张胡）
- **十三幺**：1、9万筒条+东南西北中发白各一张，再加其中一张（13张听，14张胡）

### 特殊牌型
- **清一色**：全部同一花色
- **混一色**：字牌+一门数牌
- **对对胡/碰碰胡**：全是刻子+将
- **平胡**：全是顺子+将
- **带幺九**：所有面子都含1或9
- **断幺九**：没有1、9和字牌
- **一条龙**：同门1-9各至少一张
- **大三元**：中发白三组刻子
- **大四喜**：东南西北四组刻子
- **字一色**：全部是字牌
- **绿一色**：全部是绿色的牌（2、3、4、6、8条+发）
- **九莲宝灯**：同门1112345678999，听任意一张
- **四暗刻**：四个暗刻+将
- **十八罗汉**：四个杠+将
- **清幺九**：全部由1、9组成
